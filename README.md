# amanda-landing-page

Public landing page for [Amanda](https://chromewebstore.google.com/detail/amanda-%E2%80%94-ai-study-assista/fahihghiaedfmlkkifdcfoocnghebddf) — AI study assistant Chrome extension.

Live: https://muse.ai/s/landing-page-id6f9xtyodrxs

## Contents

- `index.html` — the whole page (self-contained page; media lives in `assets/`)
- `assets/` — product screenshots, logo, and the 28s demo video (`demo.mp4`)

## Preview / deploy

Open `index.html` directly, or serve the folder with any static host
(GitHub Pages, Vercel, Netlify, Cloudflare Pages).
